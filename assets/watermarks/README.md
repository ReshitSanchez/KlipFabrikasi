# Filigranlar

Her kanal için `<kanal adı>.png` adında, **arka planı şeffaf** bir PNG koyun:

- hindistan.png
- japonya.png
- ispanyolca.png
- brezilya.png

Önerilen boyut: 400x400 piksel veya 600x200. Videoda 220 piksel genişliğe küçültülür (config: `editing.watermark_width`).
PNG yoksa kanal adı yazı olarak sağ üst köşeye basılır.
